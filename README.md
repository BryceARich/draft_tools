# draft_tools

Fantasy draft tools for ESPN football and hockey leagues: scoring rules, player values and a draft
board, built on data read through [`sports_ingest`](https://github.com/BryceARich/sports_ingest).

> **Status:** docs and conventions only. There is no app to run yet; see
> [`docs/RESUME.md`](docs/RESUME.md) for status, the next issues and the yearly draft-prep runbook.
